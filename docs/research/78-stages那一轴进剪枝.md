# `stages` 那一轴必须进 smem 剪枝（CHECKLOG I66）

§12 的候选空间设计里,轴不止 tiling 三维:`(BM, BN, BK, stages, warps, 向量宽度, layout,
split-K)`。今天的产出者仍然只有 tiling 三维(卡-C),但**剪枝这一侧连「有第四轴」都不知道**:
`prune_by_smem` 只读 `BLOCK_M/N/K`,于是

    stages=4 的空间(软件流水 4 份 A/B 缓冲)被按 **1 份**估算 ⇒ 明显放不下的点被放行

这不是「少了个优化」,而是剪枝唯一的价值(别为必然失败的点花机时)**在带流水轴的模板上失效**
—— 一个 fail-open 的守卫,而且失效时没有任何一格记录能看出它没算。

## 口径(写死并测出来)

    smem ≈ BM*BN*elem + (BM*BK + BK*BN)*elem*stages

累加器/输出那块 `BM*BN` **不随流水翻倍** —— 只乘 A/B 两块。这条口径是可被证伪的取值:
`tile_smem_bytes(64,64,32,4) = 32KiB`,`stages=4` ⇒ `+3×16KiB = 80KiB`(累加器那块 16KiB
乘 4 会得到 128KiB,两种写法在用例上分得开 —— 变异 M2 就钉这一条)。

## 三态在这里是「未观测 ≠ 1」

| 输入 | 处置 |
|---|---|
| `stages` 是 ≥1 的整数 | 按它乘;取值进 `stages_seen`(产物里可复算) |
| 没有这一轴 | 按 1 份算 ⇒ 那个数是**下界**;计 `stages_unobserved` |
| 有这一轴但值不可用(`"4"`/`0`/`-2`/`True`/`4.0`) | 同上按未观测处理,**并且说明为什么** |

为什么坏值不是「等于 1」:一个改不动的值是「**没观测到**」,不是「观测到了 1」——
把两者混起来,产物里就再也分不出「这轮没有流水轴」与「这轮的流水轴读坏了」。

为什么下界仍可摘点:下界已经超上界 ⇒ 真的只会更大 ⇒ 摘掉是**可靠**的;但反过来
「没摘」**不是**「放得下」。所以 `as_note()` 在下界口径下必须把这句话说出来
(`⚠️ N 点的估算不含多缓冲 ⇒ 是下界, 没摘不等于放得下`)—— 这条让
`tests/test_candidates.py` 里一条老断言「没摘任何点 ⇒ 没有可报的事」按设计失效,
已改成断言那句提示在场(不是放宽:同一用例的 kept/dropped/no_limit 三条一个字没动)。

## 位置与消费

`candidates.tile_smem_bytes`(唯一估算入口,新增 `stages=` 关键字)、`stages_of`(唯一读轴入口,
词表 `stages`/`num_stages`/`STAGES`,只认词表 ⇒ 认不出算未观测)、`prune_by_smem`
(`PruneResult` 新增 `stages_seen`/`stages_unobserved` + 理由里带 `×N 缓冲`)。
`template_points` 仍是剪枝的唯一入口,所以这条口径自动被模板选择器/候选队列/覆盖判据继承。

## 变异矩阵(9 处,全红)

| # | 变异 | 结果 |
|---|---|---|
| M1 | `stages` 不进估算(乘数丢掉) | ✅ |
| M2 | 累加器那块也被乘(口径写错) | ✅ |
| M3 | 未观测当 1 且不记下界 | ✅ |

| M9 | 没剪时也编出下界计数 | ✅ |

## 边界(➖/⏳)

- ➖ **估算仍是代理**:这条口径假设「A/B 两块被复制 `stages` 份」,没有 epilogue、
  没有 swizzle pad、没有 TMA 描述符;所以它是**上界的近似**而不是测量,`SMEM_SLACK=1.2`
  的宽松系数照旧。
- ➖ **L1 的源码预检那条路没有 `stages` 信息**:它从源码正则出 `BLOCK_*`,拿不到流水级数
  ⇒ 那里的估算同样是下界(同族洞,今天没有生产者能补:源码里 `num_stages` 是 Triton 启动
  参数,不在源码文本里)。
- ➖ **`warps`/向量宽度/layout/split-K 仍然没有产出者,也没有剪枝口径**(卡-C 的下半):
  `warps` 影响的是占用率而不是 smem,它需要的是另一条判据(寄存器/占用率上界),不是这里
  再乘一个系数 —— 硬塞进来会造出一个「看起来在算」的假守卫。
- ➖ 没有真模板后端:端到端仍只在假模板后端上跑过。
