**写作原则**：所有结论必须附 `file:line` 引用或实测数字或可点击的外部来源 URL。不采信任何文档自述——包括本仓库既有文档，也包括外部项目自己宣称的性能数字。

**编号约定**：`0x-` 是内部基线与真机实测（钉死现状），`1x-` 是外部技术调研，`2x-` 是吸纳决策，`3x-` 是实现后的验证报告。
