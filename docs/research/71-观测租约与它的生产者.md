# 观测租约：§11-4 的「记录」那一半终于有生产者（CHECKLOG I59）

设计 §11-4 的原话是：

> **竞争检测。** 租不到独占卡时，记录 `external_load` 并在 `evidence` 中显式标注；
> 观测降为 DEGRADED 而不是失败——**诚实降级优于静默污染**。

这句话里有**两件事**：①记录（`external_load` + evidence）；②降级（DEGRADED）。
本文记的是它们的落地现状：改前 ① 完全没有生产者（`DeviceLease` 全仓零构造点），
而 ② 早已有唯一判决者（`measurement.assess`，读 `gpu_util_pct`）——于是放置模块里那份
`degraded_by_competition` / `lease_notes(…)->bool` **是同一判定的第二处实现**，而且阈值
还不一样（放置模块 `external_load > 0`，测量侧 `gpu_util_pct > 5%`）。谁先去读它，谁就成
尺子；这正是 spine-review P1-6 那类分叉的温床。

## 1. 租约是**证据**，所以三个字段都是三态

`DeviceLease` 改前长这样：`exclusive: bool = True`、`external_load: float = 0.0`。
两个默认值都在**替观测说话**：

| 字段 | 改前默认 | 那句默认在说什么 | 改后 |
|---|---|---|---|
| `exclusive` | `True` | 「没观测 ⇒ 我独占这张卡」 | `Optional[bool] = None`（`None` = 未观测到独占性） |
| `external_load` | `0.0` | 「没观测 ⇒ 这张卡是干净的」 | `Optional[float] = None`（`0.0` = **观测到**没占用） |
| `source` | 不存在 | 这条租约凭什么在这儿 | `str = ""`（空 = 不知道出处 ⇒ 它只是一条声明） |

今天 `exclusive` **恒为 `None`**：harness 不租卡，它只是挑一张空闲的卡 —— 没有任何观测
能支撑「独占」这个声明。这不是保守，这是**不许把没测过的事写成结论**（`缺 ≠ 0 ≠ 无上限`
那一族。改前那个 `True` 会被下游当成「干净」的证据）。

`lease_evidence(lease) -> (evidence 串, 三态)` 把三态写死在一处：

| 条件 | 三态 |
|---|---|
| `exclusive is False` 或 `external_load > 0` | `contended` |
| `external_load is None`（且独占性未被观测为假） | `unobserved` |
| 其余（`external_load == 0.0`） | `clean` |

优先级刻意写在一个函数里：两个调用方各解一次，就会出现「租约说忙、档位说干净」这种
谁也查不出来的分叉。**三态不是判决** —— 降级仍然只有 `measurement.assess` 说了算。

## 2. 生产者读**同一份载荷**（一处观测、一处判决）

`observed_lease(payload, …)` 只读 `gpu_util_pct` —— 就是 `measurement.assess` 读的那个键，
**不另采一次**。各采一次的话，两个判定看的是两份观测，「租约说忙、档位说干净」就成了
可能的常态而不是不可能事件。

`device_of_payload(payload)` 把设备身份如实降级：只有索引级身份（`selected_gpu`）时
`uuid=""`，读失败时 `index=-1`。设计 §11 写着「uuid 最稳的锚，**别用 index**」——
所以这里**不许**拿 index 冒充 uuid，也不许在缺 `selected_gpu` 时编一个 0 出来
（`DeviceKey.label()` 也跟着改：没有 uuid 时印 `index=N@…`，不再印一个像 uuid 的东西）。

产物里落一格 `metrics["device_lease"]`（含 `evidence` 文本与 `competition` 三态）与
`metrics["device_lease_text"]`：§11-4 要的「在 evidence 中显式标注」今天是一格**产物**，
而不是源码里的一个承诺。

## 3. 本轮实测抓到的那条分叉：同一个 util 键，两条命运

新写的端到端用例（载荷里报 `gpu_util_pct=37`）第一次跑就红了 —— 红在
`benchmark_contaminated is False`。查下来是一个**先于本轮存在**的缺陷：

- **远程路径**：`util = bench.get("gpu_util_pct")` ⇒ 喂给 `measurement.assess` ⇒
  util > 5% ⇒ 档位降 DEGRADED、`benchmark_contaminated=True`。
- **非远程路径**：同一个键早就被搬运循环写进了 `metrics["gpu_util_pct"]`，但那条路的
  `_assess_measurement(...)` **根本没传** `gpu_util_pct` ⇒ 这个数只被搬进产物、**没人读**。

而「非远程」并不等于「仿真」：`RemoteExecutor(mode="local")` 就是在这台机器上真跑
（真机在本地模式下的读数会**带着污染证据却被判成干净**）。修法是把**产物里记的那一份**
喂给唯一判决点（`gpu_util_pct=metrics.get("gpu_util_pct")`），这与 `_assess_measurement`
自己那条「判定看的必须就是产物里记的那份」一致 —— 远程那条路读 `bench` 之所以等价，
是因为搬运循环复制的就是同一个键的同一个值。

这条值得单独记的形状：**新加的生产者会照出旧路径上的不对称** —— 我加的是「记录」，
红出来的却是「旧路径上同一份观测有两条命运」。

## 4. 仍然是纸面的部分（明写，不许读成已并行）

1. **多卡并行**：`lease_waves()` 给出了设计的 `Placement.lease(contract, n)` 形状
   （波次里装租约、`loads` 记进去、`exclusive` 恒 `None`），但它**没有多卡消费者** ——
   真机仍是单卡串行、一次调用跑完两臂。§11-1 的「异域并行省 wall clock」今天依然是
   纸面承诺。
2. **干扰域不可观测**：`interference_domain` 今天没有任何来源，于是 `can_measure_parallel`
   恒返回 False（保守串行，失败关闭的方向）。真机只能拿到 `device`/`selected_gpu`，
   拿不到 L2/时钟/NVLink 域。
3. **`pairing_conflict` 的窗口那一半**：同卡那半已有观测喂给者（doc 63），窗口
   （`candidate_window`/`baseline_window`）仍然没有 —— 它需要一个「同一次调用内的窗口号」，
   而今天 runner 报的是 `paired`/`block_ratio_medians`，没有窗口标识（I47 里明写着）。
4. **`external_load` 的观测强度**：它是**测量前**的 util 采样（`gpu_util_pct`，远端 1.2 s
   的 util 采样窗），不是测量期间的占用；`gpu_other_procs>0` 只作提示（几乎恒真，见
   `verifier.py` 那段注释）。租约不做承诺，只记观测。

## 5. 变异矩阵（11 处，全红）

| # | 变异 | 期望 | 结果 |
|---|---|---|---|
| M1 | `exclusive` 默认改回 `True`（替观测说话） | 红线 | ✅ |
| M2 | `external_load` 默认改回 `0.0`（缺 = 干净） | 红线 | ✅ |
| M3 | `external_load is None` 当作 `clean` | 红线 | ✅ |
| M4 | `exclusive is False` 不再算 `contended` | 红线 | ✅ |
| M5 | 载荷没有 util 时记 `0.0` | 红线 | ✅ |
| M6 | 缺 `selected_gpu` 时编一个 `index=0` | 红线 | ✅ |
| M7 | 拿 index 冒充 uuid | 红线 | ✅ |
| M8 | L3 不发布 `device_lease` | 红线 | ✅ |
| M9 | 非远程路径不把 util 喂给判决点（改回 `None`） | 红线 | ✅ |
| M10 | `lease_waves` 把缺 load 记成 `0.0` | 红线 | ✅ |
| M11 | `lease_waves` 声称独占 | 红线 | ✅ |

M9 就是 §3 那条分叉的**反向钉**：没有它，「记录」会再次退化成「搬进产物没人读」。

## 6. 明写没做到的

1. **真机未复跑**：本机无 GPU；全部证据是离线用例（含一次真实的 `Conductor.execute` 单轮
   链路，走 MockGPU）。
2. **多卡/干扰域/窗口**（§4 四条）都没有生产喂给者 —— 本次只把「租约」这条证据链接上。
3. **租约不进 `hardware_caps` 那类跨运行存放处**：它是**单次测量**的观测，跨运行没有意义
   （时钟/竞争不同，§9.3 的「测量缓存绝不能共享」）。
