## C 臂诊断发现

C 确实收到了绑定到起点源码的 `compute_bound` 诊断，B 的回包没有该诊断字段。C 的回包把明确使用
`tl.dot(..., input_precision="ieee")` 的候选标成 `tf32_tensor_core`，并据此报告 33.8% 达成率和 66.2%
余量。当前 roofline 根据任务 dtype、算子类型和设备能力选择 TF32 峰值，未核对候选实际计算路径。
在把这个字段用于过滤优化建议前，应区分设备支持的精度与候选使用的精度。该发现不改变本对时延读数，
本对也不足以分离诊断口径和候选选择各自对差值的影响。见 [峰值选择实现](../../../operator_agent/decide/verifier.py#L2718)。
