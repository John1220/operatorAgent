## 范围与变更

DSH 外层理解用户需求、组装最终上下文、调用模型、生成与修复；插件提供冻结领域事实、ABI、阶段材料、源码绑定的反馈、执行与验证。host 内部模型调用为 0；legacy CLI/MCP 保留。

支持任务级模型及验证预算、同 session 恢复、独立终评、取消与回收、无模型状态/取消入口；任务结束后可讨论，用户新一轮自然语言提出新任务时由 DSH 判断意图并 prepare 独立目录，无需 `/op new`。一次成功 prepare 消费该轮入口，旧额度、截止和记录不重置；意图模糊先澄清，未知在飞工作拒绝新执行。

本次收尾将默认回复简化为源码、验证结果与报告，技术细节按需展开，并要求按回执说明 atol/rtol，不将有限测试通过泛化到所有输入。生成回复由 DSH 模型完成，instructions 不保证模型所有叙述都正确，确定性判定仍以执行回执为准。

## 支持与限制

完整宿主回归在 DSH `0.2.1-rc.2` / Node `24.14.1`，个人 DSH NEXT `0.2.1-rc.4` 的用户闭环单独留证；默认 Python `3.12`。不扩展为其他宿主或设备的完整兼容矩阵。

FakeBackend 始终 `test_only`，不产生 GPU 性能结论；历史 H20 性能为 `uninformative`，收益未建立。模型硬限额只覆盖绑定后任务主模型派发，绑定前准备、辅助请求及普通讨论由 DSH 正常计费，不是整会话账单上限。多代理、专用 ReLU 诊断器、性能搜索及 v0.8 优化增强不在本次封版范围。
