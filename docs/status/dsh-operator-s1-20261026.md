## 2. 留存与兼容性边界

`complete.json` 只表示文件留存完成，不能作为正确性、性能、独立确认或入库凭据。各文件以独占创建方式写入并 fsync，文件默认 `0400`；完整回执最后写入。后端异常、写盘失败或进程中断留下的预留目录不复用，也不生成完整回执。

唯一创建入口仍位于 `run_layout.py`，没有在其他模块打开 chmod 写窗。自主运行按既有角色入口写入受保护目录；HITL 在自己预留的普通证据目录创建文件，不取得受保护目录的写权限。文件模式与哈希不构成同 UID 敌意代码隔离。

`result.json` 绑定完整源码 SHA256、冻结契约、请求的停止级别、可得的完整环境/测量事实及实现清单。HITL 留存执行前/后的磁盘实现身份，并显式标注是否稳定；这不伪称证明了 Python 已加载模块的字节。非有限诊断值使用显式 JSON 标记保存，不改写为 0。

既有协议清单由 **57 增为 61 个文件**，增加证据模块、HITL 入口、报告和布局写入口。旧实验会按原有漂移规则被识别为历史版本；没有修改 S0 快照、历史报告或解除旧执行计划的限制。
