# S5 最小对照实施（2026-10-29）

**当前决策更新**：用户要求只比较原生 DSH 和通过发布接口使用插件的 DSH，去掉 B，并对新 C 隐藏 CLI 与核心实现源码。后续以[两组插件接入方案](s5-plugin-only-comparison-20261029.md)为准；下文是已实现的历史 ABC 协议，不是新两组驱动已就绪的声明。新两组尚未运行，旧结果保持原样。

沿用现有 DSH、读取隔离、模型网关、共享预算和共同验证服务。范围限定为外层写核、读取开发反馈并自行修改、独立最终 L2；不开放内层生成/自动修复或性能调优。主比较 C−B，B−A 与 C−A 为辅助。有限任务结果不能外推为通用算子开发能力提升。

## 最小新增内容

- `s5_minimal_tasks.manifest()`：前瞻声明 6 个主输入规格，分别为 matmul `[96,128,64]` fp16、`[37,53,23]` fp32；layernorm `[12,128]`、`[11,79]` fp32；softmax `[10,128]`、`[13,83]` fp32。主规格与既有草案 14 项不重合；不声明模型训练未见或其他未登记开发记录绝无接触。主输入 contiguous，额外布局/数据模式由不改动的生产内建 correctness suite 决定，不伪称封存 holdout。
- `s5_formal_run.freeze(..., task_manifest=..., repeats=2)`：显式任务清单与重复次数进入哈希；完整 schedule 固定每个任务/重复/A/B/C，组顺序跨任务及重复轮换。36 格仅为后续研究候选规模。
- `run_one(..., repeat_id=N)`：不同重复使用独立 `runs/TASK/repeat-N/ARM`、任务身份与预算文件，保留候选和反馈；相同格重复启动拒绝，不能覆盖上一轮。旧历史批次的路径不改。
- `s5_outcomes`：已核实的模型调用/输出额度耗尽、墙钟停止、未提交以及明确候选拒绝作为该格结果继续；不把没有服务端 usage 当零，不从一个 429 文本猜测预算耗尽。网关显式记录共享账本拒绝理由。身份/资源、验证服务 unknown、证据不完整才停止后续整批；启动或收集异常也写足剩余未执行分母。
- `s5_minimal_summary.aggregate`：按完整分母统计正确/失败/未知/未执行，失败和未知成本计入已观测成本；缺成本标缺失，不按成功任务筛选。主要输出任务配对成功率差与按任务簇重采样的描述性 95% 百分位区间，重复轮先在任务内平均，不冒充独立任务。6 个任务很少，区间不保证功效或代表性，数据缺失/设施未知时不允许正向推断。DSH token 字段单列其口径，不声称为账单。

## 结果与停止口径

C 没选 MCP 或一次开发验证也没用，都是接入使用效果的观测，不删除、不重跑，也不因此判定设施故障。模型预算耗尽且无终稿时完整 L2 仍 unknown，但“预算内未完成”明确记为非成功。传输/设备/身份异常保持基础设施未知，不能伪装成模型写错。

已存在的 L1 语法/编译拒绝带完整回执时，允许按明确拒绝归类；不要求其提供尚未运行的 L2 结果。资源拒绝与传输未知仍不是明确编译失败。

## 验证

### GPU2 共享预检续行

用户在确认 GPU2 其他进程暂不计算、剩余显存足够后授权继续九格。修复后的新批次使用 GPU2（UUID `GPU-13c6c4b4-45ce-8963-1122-df2b3d72fb76`），与旧 v3 完全分开，仍不执行 36 格。默认 GPU7 独占预检规则保持；只有显式冻结的共享批次使用新策略：空闲显存至少 8192 MiB、利用率不超过 5%，目标卡计算进程 PID 必须为冻结名单的子集。原 PID 退出允许，新 PID 出现停止后续派发；不停止、重启或清空现有服务。

GPU2 的初始观察为剩余 22246 MiB、利用率 0%、7 个常驻进程。设备 pin 同时进入三个统一验证服务及主计划，资源策略同时进入计划和执行策略哈希；每格前重新读取状态。瞬时观察不构成独占保证，本批不用于性能收益结论。模型、预算、任务、轮换顺序、开发反馈和最终判定均沿用九格协议。

独立九格 v4 已全部派发并结束，4 格最终通过、4 格调用预算耗尽未完成、1 格网关 502 设施未知；未启动 36 格，见 [GPU2 结果记录](../status/dsh-operator-s5-gpu2-preflight-20261029.md)。

全部 S5 实验模块与身份/共享路径守卫 349 项通过；随后停止原因优先级与启动拒绝分母补充回归 47 项通过。包含分离重复账本、清单不重合、代码输入一致性、预算停止继续其他格、基础设施停止保留分母、无插件调用不剔除、缺失成本/未知不补零、确定性任务簇重采样，以及明确 L1 语法拒绝不误归因设施故障。

核心数值判据与容差没有改动。此前全量回归结果不替代本轮专项结果。
