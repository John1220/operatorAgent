证据等级：**A = 真机通过并有留档**；**B = 契约/单元层通过，真机未跑**；**C = 仅离线（test_only）**；**— = 不支持**。

## 1. 算子与精度

| 项 | 冻结范围 | 等级 | 证据 |
|---|---|---|---|
| 算子 | `matmul`、`relu`、`softmax`、`layernorm` | A | 八格真机 L1/L2：15 个 case、`max_error=0.0`、16.7M 元素比对；另有独立核复验 |
| 精度（声明） | `fp16`、`fp32` | A（fp16）/ B（fp32） | 本轮八格全部 fp16 真机；fp32 只到契约与单测层，**未在真机跑过完整 L2** |
| 其他算子（attention、rmsnorm、gelu…） | **不支持** | — | 契约会拒绝非上述四类；`capabilities` 列出的算子名只表示「有输入布局」，不等于验收 |

| 路径 | 冻结范围 | 等级 | 证据 |

## 3. 硬件与运行时

| 项 | 冻结范围 | 等级 | 证据 |
|---|---|---|---|
| 已验收组合 | H20（cc 9.0）+ 驱动 **580.105.08** + Python **3.10.12** + torch **2.13.0+cu130** + triton **3.7.1** + CUDA 13.0 | A | 实例回执 `2d7b78f8…`，逐格复核 |
| 其他组合 | **按实例另行验收**：换卡、换驱动、换 torch/triton 都必须重新采集探针并冻结新计划 | — | 预登记在身份变化时拒绝绑定 |

| 共享卡 | 允许，但读数必须带 `peers` 观测；同卡出现其他 harness 进程即判 `degraded` | A | 本轮多次命中 |

## 4. 契约与验证

| 项 | 冻结范围 | 等级 |
|---|---|---|
| 正确性 | 内建完整 L2：全部 case + 输入保真 + 确定性检查 | A（15 case，含 strided 派生） |
| 布局 | 内建 case 集，含 contiguous / strided / broadcast；每格**一组**声明形状 | A |
| 形状扫描 | **不支持**（`shape_sweep` 为空），单形状达标不代表输入分布回退可接受 | — |
| LayerNorm | **非 affine、最后一轴、eps=1e-5**；FP16 走 calibrated v2，输入只有 `X` | B（契约冻结；本轮真机未跑） |
| 旧式 affine LayerNorm | 保留兼容，**不在本清单内** | — |
| 性能判定 | 仅在 `measurement_validity=valid` 且差值超过该卡判决带宽时可报方向 | A（带宽来源见探针） |
| 费用/用量 | API usage 只认已校验计数；DSH 外层 usage 无法对账 ⇒ 费用保持 `unknown` | — |

## 5. 明确不承诺的

- **收益**：v0.7 不主张「插件比原生流程更快/更省」。八格 4 组里只有 1 组可判，达不到 +1 的最小可检出单位。
- **任意部署**：不含框架端到端接入、第二宿主、独立应用。
- **敌意代码隔离**：`exec_guard` 不是沙箱；MCP 工具不经 DSH 审批层。
- **任意失控核**：中断恢复只覆盖受信任固定候选、常驻 SSH runner 与显式新任务。
- **非 CUDA 迁移**：昇腾 + triton-ascend 路线仍未验证。

## 6. 失效条件（出现即重新冻结，不得沿用本清单）

1. 随包源码、`remote_scripts/`、提示词或 skills 内容变化；
2. torch / triton / CUDA / 驱动版本变化；
3. 换卡或换实例（UUID 不同）；
4. 契约、L2 case 集或容差表变化；
5. 目标卡 cc < 7.0，或探针五门任一非 pass。
