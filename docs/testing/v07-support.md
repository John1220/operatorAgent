# v0.7 支持清单（冻结）

| 项目 | 说明 |
|---|---|
| 冻结对象 | 产品版本 **0.7.0** / 插件 **0.2.0**（分支 `release/v0.7`） |
| 冻结日期 | 2026-11-05 |
| 性质 | **支持边界与证据分级**。验收范围以明确列出的硬件、精度、形状、布局和入口为准 |
| 取代 | [接入说明](phase1-connected.md#v0-7-候选支持范围)里那张「候选范围」表（保留为历史快照） |

证据等级中，**A** 表示所列条件下真机通过并有留档，**B** 表示仅契约或单元层通过，**C** 表示仅离线 `test_only` 通过，**—** 表示该范围尚未取得支持资格。§1 的 A 表示所列形状的正确性证据。Softmax 的 rc2 工作流与 v0.7.0 工件独立终评分别见[交付记录 §10–11](v07-delivery.md#11-v070-本地封版)。

**v0.7.0 的安装工件真机工作流支持范围**为 H20 上 Triton FP16 Softmax `4096×4096` 连续布局主用例及其契约内的 L2 派生用例，走显式 SSH。Matmul 和 ReLU 的 A 级为历史接入正确性证据，安装工件工作流待单独验收。性能目标达标、FP32 和 LayerNorm 仍待相应验收。

## 1. 算子与精度

以下主用例均为 H20 上的 Triton FP16 连续布局。L2 同时执行各契约的派生正确性用例。

| 算子 | 主用例形状 | 等级 | 独立终评 |
|---|---|---|---|
| `matmul` | `M=N=K=4096` | A | A、B 两臂完整 L2 均通过，各 15 个 case，主用例 `max_error=0.0` |
| `relu` | `16384×6144` | A | A、B 两臂完整 L2 均通过，各 12 个 case，主用例 `max_error=0.0` |
| `softmax` | `4096×4096` | A | A、B 两臂完整 L2 均通过，各 12 个 case，主用例 `max_error≈1.91e-6` |
| `relu` | `1024×768` | — | A 臂完整 L2 通过。B 臂主用例通过，strided 派生用例失败，故该形状的插件流程待验收 |
| `layernorm` | 非 affine、最后一轴、`eps=1e-5`，FP16 仅 `X` | B | `calibrated v2` 契约已冻结，未纳入本轮真机任务 |
| FP32 | 按候选契约声明 | B | 契约与单测覆盖，完整真机 L2 待验收 |
| 其他算子或形状 | 包括 Attention、RMSNorm、GELU | — | `capabilities` 的输入布局列表是能力发现，支持资格以本表为准 |

证据见[八格独立终评记录](../status/phase1-eight-cell-20261104.md#1-八格终态)及[预登记主用例](phase1-study.md#1-当前固定设计)。

| 项 | 冻结范围 | 等级 | 证据 |
|---|---|---|---|
| 八格实测组合 | H20（cc 9.0）+ 驱动 **580.105.08** + Python **3.10.12** + torch **2.14.1+cu130** + triton **3.8.0** + CUDA 13.0 | A | 八格计划的实例回执 `4ea72cf4…` 与 rc2 只读 SSH 预检一致 |
| 其他组合 | **按实例另行验收**：换卡、换驱动、换 torch/triton 都必须重新采集探针并冻结新计划 | — | 预登记在身份变化时拒绝绑定 |

## 4. 契约与验证

| 项 | 冻结范围 | 等级 |
|---|---|---|
| 正确性 | 内建完整 L2，覆盖契约的全部 case、输入保真及确定性检查 | A（§1 的已通过项） |
| 布局 | 每格一组连续布局主形状。L2 覆盖该契约的连续及 strided 派生用例，性能读数只对应主形状 | A（仅列明的用例） |
| 其他主布局 | 通用 strided / broadcast 主形状待另行验收 | — |
| 形状扫描 | **不支持**（`shape_sweep` 为空），单形状达标不代表输入分布回退可接受 | — |
| 旧式 affine LayerNorm | 保留兼容，**不在本清单内** | — |
| 性能判定 | 仅在 `measurement_validity=valid` 且差值超过该卡判决带宽时可报方向 | A（测量规则已在 H20 实跑，八格未形成正式 A/B 性能结论） |
| 费用/用量 | API usage 只认已校验计数；DSH 外层 usage 无法对账 ⇒ 费用保持 `unknown` | — |

## 5. 明确不承诺的

- **收益**目前未知。八格四组均缺少可比较的独立终评证据，达标差值与费用保持未知。
- **任意部署**：不含框架端到端接入、第二宿主、独立应用。
- **敌意代码隔离**：`exec_guard` 不是沙箱；MCP 工具不经 DSH 审批层。
- **任意失控核**：中断恢复只覆盖受信任固定候选、常驻 SSH runner 与显式新任务。
- **非 CUDA 迁移**：昇腾 + triton-ascend 路线仍未验证。

## 6. 失效条件（出现即重新冻结，不得沿用本清单）

1. 随包源码、`remote_scripts/`、提示词或 skills 内容变化；
2. torch / triton / CUDA / 驱动版本变化；
3. 换卡或换实例（UUID 不同）；
4. 契约、L2 case 集或容差表变化；
5. 目标卡 cc < 7.0，或探针五门任一非 pass。
